# AI-Driven Personalized Learning and Academic Performance Prediction System

A Streamlit web application that estimates a student's next exam score using machine learning, identifies weak topics from quiz results, and generates a personalized study plan.

## Features

- **Registration and login** with hashed passwords; each student sees only their own data
- **Academic records:** marks, attendance, assignment score and daily study hours, with input validation
- **Dashboard:** live metrics and subject-wise marks chart
- **Performance prediction:** compares Linear Regression, Decision Tree and Random Forest, selects the model with the lowest MAE, and includes a "what if I study more" slider
- **Quiz module:** topic-wise MCQs with instant score, correct answers, explanations and attempt history
- **Weak topic analysis:** topics classified as Needs improvement, Moderate or Strong using configurable thresholds, with improvement trend
- **Study planner:** daily plan generated from weak topics (weaker topic gets more time), with task completion tracking
- **Progress reports:** quiz improvement chart, subject-wise comparison, study goal progress and a downloadable text report
- **Early warning alerts:** low attendance, dropping quiz scores and overdue study tasks, shown on the dashboard
- **Learning resources:** revision tips and search links for each weak topic
- **Profile page:** college, learning goals and daily study time

## Tech stack

Python, Streamlit, scikit-learn, pandas, NumPy, Plotly, SQLite, joblib

## How to run

1. Clone the repository and open the folder.
2. Create and activate a virtual environment:
   ```
   python -m venv venv
   venv\Scripts\activate
   ```
3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
4. (Optional) Regenerate the dataset and retrain the model:
   ```
   python ml/make_dataset.py
   python ml/train_model.py
   ```
5. Start the app:
   ```
   streamlit run app.py
   ```
6. Open `http://localhost:8501`, register an account, and add records and quizzes.

The SQLite database is created automatically on first run.

## Important note about the data

The prediction model is trained on **synthetic demonstration data** generated by `ml/make_dataset.py`. The reported metrics show that the machine learning pipeline works; they do **not** show accuracy on real students. Predictions are estimates, not guaranteed results. The weak-topic detection and study planner are rule-based, not machine learning.
